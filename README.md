# Deniz Kebab — website demo

A responsive, bilingual (French / English) restaurant website concept inspired by Ali Haydar's food-first homepage structure, with its own visual identity.

## Website

The complete standalone HTML/CSS/JavaScript site is in [index.html](./index.html). No build command or server-side dependencies are required.

### Publish the demo for free with GitHub Pages

1. Open [Repository Settings → Pages](https://github.com/OgaPolat/DenizKebab/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main**, folder **/(root)**, then click **Save**.
4. Once GitHub finishes publishing, the demo will be available at **https://ogapolat.github.io/DenizKebab/**.

## What works

- Responsive home page and mobile navigation
- FR/EN language switch
- Sample menu, category filters, text search
- Dish details pop-up
- Accessibility features and reduced-motion support

## Before use by real customers

**This is a demonstration, not a verified restaurant website.** The dishes, descriptions and stock photographs are illustrative. Verify the menu, prices, allergens, address, operating hours, contact details, legal pages and any ordering functionality before announcing a public restaurant launch.

This separate repository does not modify Ali Haydar's production website.
